# EXCOPEN (client)

Клиент web-приложение для бронирования и создания экскурсий.

---

## Описание

Сервис дает возможность пользователю:

- Искать экскурсии по местоположению, дате и доступности

- Фильтровать результаты по категориям, цене, 
продолжительности и рейтингу, выбранным тегам

- Добавлять экскурсии в избранное для быстрого доступа в будущем

- Просматривать список ранее открытых экскурсий

- Читать и оставлять комментарии к экскурсиям

- Бронировать экскурсии

- Редактировать личный профиль 
(имя, фамилия, контактные данные, предпочтения и тд.)

- Проходить регистрацию и авторизацию для сохранения данных

Определенная часть функционала 
(поиск и просмотр найденных экскурсий, добавление в избранное) 
доступно в том числе и не для авторизованных пользователей, 
при помощи **local storage**.

## Стек технологий

- **React**
- **TypeScript**
- **Vite**
- **Eslint**
- **CSS + Tailwind + ShadCN + Module CSS**
- **React Router Dom**
- **Axios + Tanstack Query**
- **MobX + React Context**

Архитектура клиента построена на основе метологии FSD

## Установка и запуск

Запуск сборки локально:

```bash
git clone https://github.com/excopen/excopen.git
cd client
npm build
npm preview
```

Запуск через хостинг:

1. Разбудите сервер (в рамках бесплатного тарифа сервер на хостинге засыпает через 5 минут без запросов)
Можете запустить в Postman следующий запрос 
(https://excopen-prod-back-v0-1-1.onrender.com/api/tags), 
после получения ответа, можно использовать приложение
2. Откройте ссылку https://excopen.ru

## Поддержка приложения

На данные момент приложение продолжает улучшаться, могут быть проблемы с следующими фичами:

- Выход из аккаунта
- Создание/редактирование экскурсии
- Мелкие баги в верстке
- Идет доработка бронирование
- Добавляется регистрация для гида
